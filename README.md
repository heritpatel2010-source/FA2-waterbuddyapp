# WaterBuddy – A Smart Hydration Tracking Application

WaterBuddy is a simple, interactive and user-friendly hydration tracking application developed using Python. The main purpose of this project is to encourage people to develop healthy water-drinking habits by helping them monitor their daily water intake. In our busy daily routines, we often forget to drink water regularly or keep track of how much water we have consumed throughout the day. WaterBuddy aims to solve this problem by providing a convenient digital platform where users can record, monitor and manage their water consumption in an organised way.

The application is designed with an attractive and easy-to-understand interface that makes it suitable for everyday use. Users can record their water intake by selecting quick-add options such as 150 ml, 250 ml and 500 ml, or by entering a custom quantity according to their consumption. The application automatically calculates the total amount of water consumed and displays the remaining quantity required to reach the user's daily hydration goal.

WaterBuddy also includes a daily goal-setting feature that allows users to establish their own water intake target. A visual progress bar and hydration dashboard help users understand their progress at a glance. The application displays important information such as total water consumed, remaining water and the percentage of the daily goal completed. These features make tracking water intake more interactive and motivating.

Another important feature of WaterBuddy is its drink history, which allows users to review their recorded water consumption. Users can undo their latest entry if they make a mistake, reset their daily progress when necessary and download their hydration records in JSON format for future reference. The application also provides helpful hydration tips and motivational messages to encourage users to maintain consistency in their daily routine.

The project is developed using Python as the main programming language and Streamlit to create the interactive web-based interface. Python is used for calculations, data processing and application logic, while Streamlit helps display the dashboard and interactive controls in a web browser. JSON is used to organise and export the hydration records.

Overall, WaterBuddy demonstrates how programming and digital technology can be used to address a simple real-life problem. It promotes awareness of daily water consumption and encourages users to build more consistent hydration habits through an accessible and engaging digital solution.
