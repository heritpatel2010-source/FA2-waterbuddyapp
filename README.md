# FA2-waterbuddyapp
WaterBuddy – A Smart Hydration Tracking Application  WaterBuddy is a simple and user-friendly hydration tracking application developed using Python. The main purpose of this project is to encourage people to develop healthy water-drinking habits by helping them monitor their daily water intake.
